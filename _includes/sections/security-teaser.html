Security

Encryption you can describe to an auditor

Secrets are sealed with authenticated AES-256-GCM using a random IV and a per-secret salt. Keys are derived with PBKDF2 at 600,000 iterations and HKDF-SHA256. Object keys carry 256 bits of entropy. Personal folders are decryptable by their owner and the recovery account, and nobody else.

  • {% include components/icon.html name="check" %}Per-user key distribution, so revoking access actually revokes it
  • {% include components/icon.html name="check" %}Existing vaults migrate lazily, without a maintenance window
