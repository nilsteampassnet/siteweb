Linux password rotation

Your vault knows the root password. Teampass can change it.

LAPR rotates local Linux account passwords over SSH, straight from the item that stores them. Agentless — nothing is installed on the target servers — and part of the open-source server, not a separate product.

  • {% include components/icon.html name="check" %}The server changes first. Teampass only records a password the machine has already accepted.
  • {% include components/icon.html name="check" %}Reusable policies. Frequency, length and character sets, applied to as many accounts as you like.
  • {% include components/icon.html name="check" %}Host key verified before the credential is sent. A changed fingerprint blocks the rotation instead of logging a warning.
  • {% include components/icon.html name="check" %}Retries, then suspends. An unreachable host is never hammered, and the failure is visible rather than silent.
  • {% include components/icon.html name="check" %}An audit log that never holds a secret, and its own permission, separate from administration.
