{% comment %} Analytics. The former Universal Analytics property was shut down by Google in 2023 and had stopped collecting anything. Nothing is loaded unless `analytics.provider` is set in _config.yml — a security product should not ship a tracker its visitors did not expect. provider: "google" -> GA4 via gtag.js, needs analytics.measurement_id (the data stream's G-XXXXXXXXXX, not the numeric property ID). provider: "plausible" -> self-hosted Plausible, needs analytics.script. Prior blocking, not just Consent Mode. Google's tag is *not* requested at all until the visitor has accepted: consent defaults are declared denied, and `gtag/js` is only injected from tpConsent.accept(). A "denied" Consent Mode tag still pings Google cookielessly, which the CNIL does not treat as exempt — so we never load it in the first place. {% endcomment %} {%- if site.analytics.provider == "plausible" and site.analytics.script != "" %} {%- endif %} {%- if site.analytics.provider == "google" and site.analytics.measurement_id != "" %} {%- endif %}
