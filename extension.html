The arrangement

Teampass stays open-source. The extension goes further.

The server remains free, open-source and self-hosted — always. The extension is a professional add-on for people who live in the browser all day.

Sovereignty

Free trial

Activation

Getting the trial running

  1. Update your instance

    Install or upgrade to Teampass v3, then open Settings > Extension in the administration area.

  2. Install the extension

    From the Chrome, Firefox or Edge store.

  3. Send us two values

    Email {{ site.email }} with the FQDN of your instance and its instance token, both shown in that settings screen.
