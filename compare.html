The case for Teampass

Three reasons teams pick it anyway

{% include components/icon.html name="clipboard-check" %}

Governance is not an upsell

Recertification campaigns, evidence export, classification and rotation tracking ship in the free server. Elsewhere the equivalent features — where they exist at all — sit behind an enterprise tier.

{% include components/icon.html name="folder" %}

A real folder and role model

A tree of folders with roles and per-user overrides, rather than flat collections. It maps onto how organisations actually delegate access — per client, per environment, per team.

{% include components/icon.html name="server" %}

A stack most teams already run

PHP and MySQL. No .NET, no container orchestration, no separate identity service. If you host a web application today, you can host this.

{% include components/icon.html name="info" %}

How to use this page. Do not choose a password manager from a comparison table — including this one. Install the two you are weighing, model your real folder structure in each, and try an offboarding. The differences that matter show up in fifteen minutes of that, and never in a feature grid.
