Free channels

Start here — it is usually faster

Public channels keep answers searchable for the next person with the same problem, which is why they are the default rather than a fallback.

{% include components/icon.html name="book" %}

Documentation

Installation, configuration, administration and the API. Most questions are answered here, and it tracks the current release.

Open the docs {% include components/icon.html name="external-link" %} {% include components/icon.html name="users" %}

Discussions

Setup questions, advice, feature ideas and shared experience from other administrators. The right place for "how should I…" questions.

Ask a question {% include components/icon.html name="external-link" %} {% include components/icon.html name="alert-triangle" %}

Issues

Bug reports. Include your version, PHP version and the steps to reproduce — a report that can be reproduced gets fixed far faster than one that cannot.

Report a bug {% include components/icon.html name="external-link" %} {% include components/icon.html name="shield" %}

Security reports

Vulnerabilities go through the security policy, not the public tracker. Fixes are published as advisories once released.

Read the policy {% include components/icon.html name="external-link" %}

Priority support

Your defects and messages handled ahead of the queue. Sensible when an outage in Teampass means your team cannot reach production credentials.

Sponsored development

Fund a feature you need. Scope and timeline agreed up front, and the result ships in the open-source release rather than as a private fork you then have to maintain.

Discuss a feature {% include components/icon.html name="arrow-right" %}

Deployment assistance

Help sizing, installing, integrating with your directory or migrating from another manager — particularly useful for the first large rollout.

Request a quote {% include components/icon.html name="arrow-right" %}
{% include components/icon.html name="heart" %}

Sponsorship

Back the project through GitHub Sponsors. It is the least transactional option on this page, and the one that keeps everything else free.

Become a sponsor {% include components/icon.html name="external-link" %}
{% include components/icon.html name="alert-triangle" %}

Never send credentials to get support. Nobody working on Teampass will ask for your instance password, a database dump containing secrets, or the contents of an item. Logs, versions and error messages are enough — and if they are not, we will ask for something specific and safe.
